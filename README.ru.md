# Sensitivity Randomizer

[GitHub overview](README.md) · [Detailed English documentation](README.en.md)

Автор: [dinati.ru](https://dinati.ru/)

Универсальная Windows-утилита для variable-practice тренировок в любой игре.
Она периодически меняет постоянный `Sensitivity Multiplier` через официальный
Raw Accel и никогда не связывает чувствительность со скоростью движения мыши.

Важно: программа не меняет физический DPI мыши и не записывает настройку
чувствительности в игру. Поля `Mouse DPI` и `Base sensitivity` используются
только для отображения effective sensitivity и eDPI. Реальное изменение
выполняется через `Profile.outputDPI` Raw Accel и действует как постоянный gain.

## Возможности

- `Balanced Coverage`: восемь логарифмических зон за цикл, четыре значения ниже
  и четыре выше `1.000`, каждая зона посещается ровно один раз;
- редактируемый диапазон multiplier от `0.10000` до `10.00000`;
- взаимно обратные границы по формуле `min × max = 1`;
- `Smooth Random Walk`, `Centered Gaussian` и классический `Linear Uniform`;
- случайный или фиксированный интервал смены;
- таймер сессии, recalibration phase, повторяемый seed;
- импорт и экспорт проверяемых JSON-профилей;
- русский, английский, немецкий, испанский, польский и украинский языки;
- тёмная, светлая и пастельная темы с сохранением выбора;
- компактный WPF-интерфейс, live-график и лёгкие анимации без анимации layout;
- F8 Start/Stop, F9 Reset, F10 Pause;
- CSV/JSON-логи и итоговая статистика;
- readback после каждой записи и отдельный `SensitivityResetGuard.exe`;
- блокировка запуска при обнаружении speed-based acceleration.

## Установка

1. Установи [Raw Accel v1.7.1](https://github.com/RawAccelOfficial/rawaccel/releases/tag/v1.7.1) и перезагрузи Windows.
2. Установи [Microsoft Visual C++ Redistributable 2015-2022 x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).
3. Разблокируй скачанный ZIP в его свойствах, если Windows показывает такой пункт.
4. Полностью извлеки архив в обычную локальную папку.
5. Запусти `SensitivityRandomizer.exe` рядом с `wrapper.dll`,
   `Newtonsoft.Json.dll` и `SensitivityResetGuard.exe`.

Не запускай EXE прямо из ZIP и не копируй его отдельно от остальных файлов.
Приложение рассчитано на Windows 10/11 x64 и .NET Framework 4.7.2 или новее.

Текущая RC-сборка не имеет публичной Authenticode-подписи, поэтому SmartScreen
может показать предупреждение. Размер основного EXE небольшой, потому что WPF
входит в .NET Framework, а Raw Accel wrapper и JSON-библиотека поставляются
отдельными DLL. Проверяй комплект по `SHA256SUMS.txt` или собирай его из
приложенных исходников. Процесс подписи подготовлен в [SIGNING.md](SIGNING.md).

## Первый запуск

1. В каждом профиле Raw Accel выставь `Accel Type = Off/noaccel` и нажми Apply.
2. Запусти программу и нажми `Проверить`.
3. Нужны `constant gain`, отсутствие acceleration и multiplier `1.000`.
4. Выбери диапазон, режим и интервалы.
5. Нажми Start.

Если активен speed-based acceleration, Start блокируется. Программа не
отключает кривую молча.

## Balanced Coverage и симметрия

Для default-диапазона `0.50-2.00` цикл покрывает зоны:

```text
0.500-0.595  0.595-0.707  0.707-0.841  0.841-1.000
1.000-1.189  1.189-1.414  1.414-1.682  1.682-2.000
```

Порядок зон перемешивается. За полный цикл значения ниже и выше единицы
встречаются строго поровну, а низкие, средние и высокие части каждой половины
диапазона получают одинаковое число посещений.

При включённой симметрии изменение одной границы пересчитывает другую:

```text
0.57000 -> 1.75439
1.75000 -> 0.57143
0.10000 <-> 10.00000
```

Это мультипликативная симметрия. Геометрическое среднее полного цикла равно
`1.000`. Арифметическое среднее для `0.50-2.00` выше единицы, хотя количество
значений по обе стороны остаётся `50/50`. Итоговый отчёт отдельно показывает
арифметическое и геометрическое среднее, а также баланс по сменам и времени.

## Интерфейс

- `Основное`: режим, границы и интервалы;
- `Дополнительно`: расчёт eDPI, длительность, seed и логи;
- `Справка`: запуск, режимы и безопасное отключение.

Нерелевантные параметры скрываются. Например, mean и sigma показываются только
для Gaussian, а maximum step и return strength только для Random Walk.

Язык и тема переключаются справа в заголовке и сохраняются в `config.json`.
Анимации применяются только к появлению интерфейса, вкладкам и hover-состояниям.
Размер и расположение элементов во время resize не анимируются.

## Проверка работы и отключения

Во время сессии статус должен быть `RUNNING`, multiplier должен меняться, а
live-график получать новые точки. Readback Raw Accel должен совпадать с текущим
значением.

Для отключения нажми Stop или Reset, дождись `OFF` и `1.000`, затем нажми
`Проверить`. При штатном закрытии окна программа сначала возвращает `1.000`,
после чего завершает основной процесс. Она не остаётся в tray и не добавляет
себя в автозапуск. ResetGuard может завершаться ещё несколько секунд.

Raw Accel намеренно задерживает применение примерно на одну секунду, поэтому
минимальный интервал равен `1.25 s`, а Reset обычно занимает около секунды.

## Файлы пользователя

```text
%LocalAppData%\SensitivityRandomizer\config.json
%LocalAppData%\SensitivityRandomizer\startup.log
%LocalAppData%\SensitivityRandomizer\logs\session_*.csv
%LocalAppData%\SensitivityRandomizer\logs\session_*.json
%LocalAppData%\SensitivityRandomizer\crash.log
%LocalAppData%\SensitivityRandomizer\reset-guard.log
```

При первом запуске 1.2 программа переносит прежний `config.json`, если новый
ещё не создан. Старое имя JSON-поля base sensitivity и прежний формат portable
config также читаются для совместимости. Новые файлы используют только новое
название продукта.

## Safety model

Перед каждой сменой программа:

```text
DriverConfig.GetActive()
  -> меняет только outputDPI = 1000 × multiplier
  -> DriverConfig.Activate()
  -> DriverConfig.GetActive()
  -> сверяет requested и actual для всех профилей
```

Stop, Reset, завершение таймера и штатное закрытие возвращают multiplier к
`1.000` с readback. ResetGuard пытается сделать то же после аварии. Абсолютная
гарантия невозможна при отключении питания, kernel crash, поломке драйвера или
одновременном принудительном завершении обоих процессов. В таком случае открой
Raw Accel, выставь `1.000` и нажми Apply вручную.

```powershell
PowerShell -ExecutionPolicy Bypass -File .\build.ps1 -Configuration Release
```

## Anti-cheat

Приложение не читает память игры, не инжектирует DLL, не анализирует экран, не
двигает мышь и не создаёт input. Оно управляет Raw Accel вне процесса игры.
Это снижает техническую похожесть на чит, но не является гарантией одобрения
конкретным античитом. Неподписанный custom EXE не одобрен FACEIT автоматически.
Для защищённых матчей безопасный стандарт остаётся прежним: сначала получить
письменное подтверждение поддержки или не запускать программу вместе с AC.
